    Plug in your own trained model

    Train softmax or logistic regression in scikit-learn on the exported CSV, then paste {"w":[[…4],[…4],[…4]],"b":[…3]} with class order healthy, overloaded, at_risk and feature order load (0 to 1.3), temp °C, slope °C/min, voltage deviation (0 to 1). Until you load one, a starter model runs.

    ESP32 data format

    Send one line per reading at 115200 baud: {"t":45.2,"i":1.8,"v":229} or 45.2,1.8,229 (°C, A, V). For HTTP mode the URL must return that JSON and allow CORS. Chrome or Edge is needed for USB. When using the hosted page, save it and open it as a local file if USB or HTTP is blocked.
